# physics-test
A physics test that helps the user solve for mass, weight, or gravity depending on their choosing. 

## features
1. User inputs either M, G, or W which determines which test they would like to take. Around four problems are given within each test
2. Users are then prompted with their answer after each problem using the second number after the decimal to round up. After prompted with their answer users are required to enter the correct units for example; kg, N, or m/s^2. The answer is automatically deemed as incorrect if the answer is rounded, answer isn't correct, or if the correct units are inputted.
3. After the user has inputted all of the program they are given their final score for that quiz

### concepts used
1. python basics, with iteration, selection, and sequence
2. dictionaries, list, for loops, variables, user input
